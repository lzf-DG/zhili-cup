# 智理杯 · Pre大师·沉浸版

**多智能体答辩模拟系统** —— 输入主题、上传 PPT，三位 AI 评委「三堂会审」，答辩后自动生成五维复盘报告。

> ⭐ **开箱即用**：默认内置 Mock 引擎，**无需任何 API 密钥、环境变量、数据库**即可完整体验全流程。

---

## 🚀 快速上手（3 步跑起来）

### 环境要求

| 需要 | 要求 |
|---|---|
| Node.js | **20.19+ / 22.12+ / 24**（Vite 8 硬性要求，装太老会启动报错） |
| 浏览器 | Chrome / Edge（语音输入依赖 Web Speech API） |
| 其它 | 无（LibreOffice 等为可选项，见下） |

### 启动命令

```bash
cd pre-master-app
npm install        # 首次约 1-3 分钟
npm run dev        # 同时启动 前端5173 + 后端3001
```

打开 **http://localhost:5173** 即可使用。

---

## 📖 使用方式（一次完整答辩）

1. **设定论题页** — 输入答辩主题，点「踏入论道台」。
2. **汇报阶段** — （推荐）上传 3–5 页带标题正文的 .pptx；点「开始答辩」→ 粘贴/输入汇报内容 → 点「结束汇报」。此时王教授会先给出 **20–50 字整体评价**，再进入提问。
3. **答辩阶段** — Host Agent 调度三位评委轮流提问：
   - **王教授**（严格）：盯逻辑漏洞、数据依据
   - **李教授**（温和）：关注创新点、研究意义
   - **张同学**（好奇）：从听众视角问通俗问题
   
   支持**打字或语音**回答；反问可让评委澄清所指；**点名某位评委**可切换提问人；跨评委自动去重，不会重复问同一问题。
4. **复盘报告** — 点「结束答辩」→ 生成 **总体 / 逻辑 / 内容 / 表达 / 时间** 五维评分 + 亮点与改进清单 + 逐轮问答回顾。

### 接入真实大模型（可选）

默认 Mock 模式零门槛可用；想接入真实 AI，在欢迎页点「**API 设置**」填入 Base URL / API Key / 模型即可。配置保存在本机浏览器 localStorage，请求经本地后端代理转发，密钥不外泄。

---

## 🖥️ PPT 投影说明（可选项，不装也能用）

- **默认回退**：后端用 JSZip 解析 .pptx，提取每页文本与内嵌图片用于投影，无需任何系统工具。
- **高清 PNG 效果**：想获得「高清渲染到黑板」的视觉效果，需安装 LibreOffice + Poppler（Windows 用安装包或 `winget`；macOS 用 `brew install --cask libreoffice && brew install poppler`）。检测不到时自动静默回退。

## ⚠️ 常见问题

| 现象 | 处理 |
|---|---|
| `npm install` 慢 / 失败 | `npm config set registry https://registry.npmmirror.com` 后重试 |
| 启动报 Node 版本错误 | 升级到 Node 20.19+ / 22.12+ |
| 打开页面提示「后端 3001 未启动」 | 确认 `npm run dev` 正常跑、3001 端口未被占用 |
| 语音输入没反应 | 使用 Chrome / Edge，并在地址栏授权麦克风 |
